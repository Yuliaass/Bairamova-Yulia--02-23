# Data Analyst Portfolio — 2 учебных проекта

Репозиторий с **двумя полностью воспроизводимыми pet-проектами** для Junior Data Analyst. Все данные **синтетические**, созданные специально для обучения. Никакие результаты не выдаются за реальные бизнес-метрики.

| Проект | Что демонстрирует | Файлы |
|---|---|---|
| [Велопрокат](bike-share-analysis/) | Python, очистка, EDA, группировки, визуализация | Jupyter Notebook, CSV, графики |
| [Интернет-магазин](ecommerce-sql-analysis/) | SQL JOIN, CTE, агрегаты, KPI, визуализация | SQLite, SQL, Python, графики |

## Быстрый старт

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cd ecommerce-sql-analysis && python run_analysis.py
```

Для первого проекта запустите `jupyter notebook bike-share-analysis/analysis.ipynb` из корня репозитория, затем выполняйте ячейки (или откройте Notebook в VS Code). **Важно:** notebook использует относительный путь `data/`, поэтому запускать его следует с рабочей директорией `bike-share-analysis`.

## Публикация
Можно загрузить весь каталог одним GitHub-репозиторием или каждую подпапку отдельным репозиторием (в последнем случае скопируйте `requirements.txt` в корень каждого проекта и исправьте пути установки в README).

## Этика портфолио
Код и данные подготовлены как учебные примеры. Перед указанием проектов в резюме выполните код самостоятельно, проверьте результаты и будьте готовы объяснить запросы, очистку данных и ограничения синтетической выборки.
